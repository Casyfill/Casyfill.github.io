## Hi, I'm Philipp

Senior Applied Scientist at [StreetEasy](https://streeteasy.com) (Zillow Group). I build production
machine learning end to end — the model, the service that serves it, and the data foundation
underneath. Property valuation, entity resolution, ranking and retrieval, and inferring the
attributes a listing forgot to mention.

Nine years in one domain taught me that the interesting part is almost never the model. It's the
boundary: where a modeling choice collides with a latency budget, where a data contract prevents a
failure three teams away, where deciding *not* to answer is the product decision. I write those up
at **[casyfill.github.io](https://casyfill.github.io/)** — most recently
[on deciding two records describe the same sale, with no labels and no stated cost of a wrong
answer](https://casyfill.github.io/matching-without-labels/).

Before this: architecture, then urban data at Strelka, then NYU CUSP. The cities thread never left —
spatial data and visualization are still where I go when I get to pick.
